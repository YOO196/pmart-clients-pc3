# MFC 백오피스 대시보드 "센터 도면 · 작업자" — 작업자 현재 위치(도면 좌표)를 읽을 API 가 없음

보낸 앱: mfc-backoffice (PC 3)
받는 백엔드 영역: mfc (mfc-capacity·mfc-fulfillment)
날짜: 2026-11-21

## 상황
- 사용자 요청(2026-11-21): 센터 대시보드에 위에서 본 도면을 두고 작업자 이동을 점으로 보고 싶다(가상 현장 `pmart-mfc-simulation` 처럼).
- 도면은 가상 현장 평면 배치(가정, 실측 아님)를 옮겨 그렸다. 칸 위치는 mfc-location `FloorPosition`(x 동쪽·z 남쪽 m, 원점 북서 모서리)과 같은 좌표계다.
- 작업자 현재 위치를 주는 계약이 없다. 지금은 **목 모드에서만** 재직·휴게·맡은 작업 종류(서버 값)로 역할을 정하고 통로를 걷는 시뮬레이션으로 그린다. 실서버에서는 점을 그리지 않고 "작업자 위치 API 없음"을 보인다.

## 요청(둘 중 하나 — 백엔드 판단)
1. 위치 사본 조회: `GET /mfcs/{mfcId}/worker-positions` → `[{ workerId, xM, zM, source: SCAN|ESTIMATE, at }]`
   - 원천 후보: PDA 마지막 스캔 칸의 `position`(칸 스캔 = 그 칸 앞), 작업 단계 이벤트(피킹 칸 도착·포장대 도착).
   - 정확한 실내 측위가 아니라면 `source: ESTIMATE` 와 기준 시각으로 "마지막으로 본 자리"임을 알려 주면 화면이 그렇게 표시한다.
2. 작업자 활동 목록에 마지막 스캔 칸(`locationId`·시각)을 더하기 — 화면이 칸 `position` 으로 찍는다.

## 화면 쪽 약속
- 서버가 준 값만 실제 위치로 그린다. 추정이면 "추정·기준 시각"을 함께 보인다. 위치를 못 읽으면 점을 지우고 "조회 실패"(0명·빈 도면으로 바꾸지 않음).
- 칸 `position` 이 대부분 비어 있다(목 데이터도 1칸). 실제 도면 좌표 등록이 먼저 필요하면 알려 주세요.
