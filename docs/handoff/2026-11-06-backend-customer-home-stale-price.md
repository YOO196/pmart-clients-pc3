# [pmart-clients → pmart-backend] 회신: 고객 앱 홈 가격 갱신 (2026-11-06)

- 대상 요청: `../pmart-backend/docs/handoff/2026-11-06-clients-request-customer-home-stale-price.md`
- 원인 진단(홈 provider 가 화면을 떠나도 남아 쇼핑 주소가 바뀔 때만 다시 조회)은 맞다.

## 고른 방법
- 1번(당겨서 새로 고침)은 이미 있었다(`home_screen.dart` `RefreshIndicator`).
- 2번(앱이 다시 앞으로 올 때)은 쓰지 않는다. 이번 현상은 앱이 백그라운드로 가지 않은 채 홈 → 상세 → 홈을 오갈 때 생겼다. 또 결제창·소셜 로그인에서 돌아올 때마다 불필요하게 다시 읽게 된다.
- 대신 **홈이 다시 보일 때**(상품 상세 등 올린 화면에서 뒤로, 다른 탭에서 홈 탭으로) 마지막 홈 조회가 **1분 이상** 지났으면 다시 읽는다. 3번(일정 시간)을 이 시점에만 적용한 셈이다.
- 다시 읽는 동안에는 지금 홈을 그대로 두고, 응답이 오면 바꾼다. 실패하면 홈이 오류로 보인다. 쇼핑 주소가 바뀌어 다시 읽을 때는 전처럼 자리 표시를 보인다.
- 새로 고침 때는 "다시 불러오기"한 영역도 새 홈 응답으로 바꾼다. 남겨 두면 그 영역만 옛 가격이 된다.

## 한계
- 홈을 보고 있는 채로 가만히 있으면 바뀌지 않는다. 당겨서 새로 고침하거나 다른 화면에 갔다 오면 바뀐다.
- 홈에 다녀온 지 1분이 안 됐으면 다시 읽지 않는다.
