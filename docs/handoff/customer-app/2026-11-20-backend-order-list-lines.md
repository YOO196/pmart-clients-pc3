# 요청 — BR-68 주문내역 카드에 상품 줄·센터 이름

- 보낸 앱: customer-app (PC 1)
- 받는 백엔드 영역: platform (order-service)
- 계기: 사용자 2026-11-20 캡처(레퍼런스 주문내역) — 끝난 주문 카드가 "센터 이름 · 날짜 · 상태" 머리 아래 **상품마다 한 줄**(사진·이름·가격·수량·⊕ 담기, 판매 끝난 상품은 흐리게 "판매가 끝났어요")과 "모든 상품 보기 ⌄", 결제금액, [같은 상품 담기]를 보인다. 지금 `GET /orders` 항목에는 대표 상품 하나(`representativeItem`)뿐이라 그릴 수 없음.

## 요청
- R1. `GET /orders` 항목(`OrderSummary`)에 **주문 행 목록**(앞 5개 정도면 충분, 전체 수는 `itemCount`): `orderLineId · productId · sku · productName(사본) · optionLabel(사본) · quantity · lineAmount` — 카드에서 줄마다 보인다. 카드마다 상세를 따로 부르지 않게(목록 20건이면 20번 호출).
- R2. 항목에 **센터 이름**(`mfcName`, order 0.15.0 상세의 `mfcName` 과 같은 값) — 카드 머리.
- R3(선택). 행마다 지금 **살 수 있는지**(판매 중/끝남) — "판매가 끝났어요" 흐림과 ⊕ 숨김. 없으면 앱은 ⊕ 를 눌렀을 때 장바구니 서버 판정으로만 알린다(지금처럼).

## 앱이 한 것(2026-11-20)
- 주문내역 필터를 캡처처럼: 맨 앞 ↻(조건이 걸렸을 때), 검색·조회 기간·주문 상태·정보 알약(고른 조건은 검게 + 고른 이름), 조회 기간·주문 상태 시트(제목 + ✕, 알약, [↻ 초기화][적용]).
- 카드: 대표 상품 한 줄 + 결제금액. R1~R2 가 오면 줄 목록·센터 이름을 그린다(값이 없으면 지어내지 않음).
- 조회 기간의 "시작월·종료월" 고르기는 계약이 `from` 날짜 하나뿐이라(끝 없음) 빠짐 — 필요하면 `to` 를 함께 열어 주세요.
