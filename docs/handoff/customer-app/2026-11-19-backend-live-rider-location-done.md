# 회신 — 배송 현황 지도: 라이더 위치를 SSE 로 실시간 (고객 앱 반영)

- 보낸 앱: customer-app (PC 1)
- 받는 백엔드 영역: delivery (PC 5 — delivery-tracking)
- 원 문서: `../pmart-backend/docs/handoff/clients/all/2026-11-19-notice-live-rider-location.md`(백엔드 PR #231) + PC 5 세션 요청(사용자가 전달, 2026-11-19)
- 반영: pmart-clients main 에 직접 커밋(PC 1 은 PR 없이 원본 main 에 넣는다) — 커밋은 아래 "커밋"

## 한 것 (요청 1~6)
1. **마커 이동을 SSE 로** — `ETA_UPDATED`·`STAGE_CHANGED` 의 `eta.riderLocation` 으로 마커를 옮긴다. 이전 점에서 새 점으로 1초(`Poi.move(…, 1000)`).
   구독 값이 있으면 그것만 쓴다(구독이 null 을 주면 예전 조회 위치로 채우지 않는다).
2. **주기 조회는 끊겼을 때만** — `GET /eta` 10초 조회는 구독이 끊겼거나 다시 붙는 동안(배달 중일 때만). 구독이 붙어 있으면 읽지 않는다.
3. **오래된 위치** — `staleSeconds > 60` 이면 마커를 흐리게(투명도 0.4 스타일로 바꿈) + 시트에 "라이더 위치를 확인하고 있어요". 새 이벤트로 60 이하가 되면 되돌린다.
4. **위치 없음** — `riderLocation` null 이면 라이더 마커를 숨기고 내 배송지 마커·도착 예정만. 내 배송지 핀도 없으면 지도 없이 단계·"확인하고 있어요". 픽업 전에는 지금처럼 단계 문구만(지도 없음).
5. **연결 정리** — 화면을 떠나거나 앱이 가려지면 구독을 닫고, 돌아오면 다시 연다(그대로 있던 동작). `STREAM_END` 면 닫고 다시 열지 않는다.
6. **목** — `MockOrdersRepository(liveRiderInterval:)` — 목 앱은 5초마다 배달 중 배송(dlv-s2)에 위치가 바뀐 `ETA_UPDATED` 를 흘린다. `riderStaleSeconds` 로 오래된 위치를 시험.

## 안 한 것
- **MFC 마커**: 요청 4 의 "MFC 마커"는 그리지 않는다 — 고객이 센터 좌표를 받을 계약 경로가 없고(center-master 는 직원 전용), 2026-11-19 사용자 결정으로 요청도 하지 않았다.
- 지나온 동선·예상 위치는 그리지 않는다. 좌표는 로그·저장소에 남기지 않는다(`RiderPosition.toString` 에 좌표 없음).
