- 보낸 앱: customer-app (PC 1)
- 받는 백엔드 영역: platform (customer-assistant-service — FAQ)
- 계기: 사용자 2026-11-23 고객센터 레퍼런스 추가 "3. 자주 묻는 질문 - 답변 펼침·도움이 되었어요" — 펼친 답 아래 [😊 도움이 되었어요] [😐 수정이 필요해요] 두 버튼. 앱은 FAQ 를 목록 안에서 펼치게 바꿨으나(2026-11-23) 의견을 받는 API 가 계약에 없어 버튼을 넣지 않음. 사용자 "응 br 보내줘".

## 요청 R1
- `POST /customer-assistant/faqs/{faqId}/feedback` (회원 고객 — FAQ 조회와 같은 권한, `Idempotency-Key`): 본문 `{helpful: boolean}`.
- 한 고객이 한 FAQ 에 하나(다시 누르면 바꾸기 — 마지막 값). 응답에 지금 내 값 `{helpful}`.
- FAQ 항목(`GET /customer-assistant/faqs`·`/faqs/{faqId}`)에 회원이면 `myFeedback: boolean|null`(이미 누른 버튼을 눌린 모양으로) — 넣을지 서버 판단.
- 집계(도움 N·수정 필요 N)는 운영(백오피스) 용 — 고객 화면엔 숫자를 보이지 않는다.
- 질문 Q1: [수정이 필요해요]에 글(무엇이 틀렸는지)을 받을지 — 앱 기본은 글 없이 한 번 누르기(레퍼런스처럼).

## 앱
- 펼친 답 아래 두 버튼(레퍼런스 모양). 누르면 확정 응답 뒤에만 눌린 모양 + "의견 고마워요"(짧은 알림). 결과 불명은 같은 키로 다시. 비회원은 FAQ 자체를 못 본다(지금 서버 403).
