# 요청 — 상품 리뷰 추천순·옵션 필터·도움돼요 (BR-76)

- 보낸 앱: customer-app (PC 1)
- 받는 백엔드 영역: platform (review-service)
- 작성: pmart-clients, 2026-11-21 — 사용자 "상품 리뷰에서도 추천순/최근등록순, 필터(상품 옵션) 넣어줘", "내가 쓰지 않은 다른 사람 리뷰에 도움돼요 버튼 누를 수 있도록", "회원만 누르게 해줘"
- 기준 계약: `review-service.yaml` 0.5.0 — `GET /products/{productId}/reviews` 는 `sort`(NEWEST·RATING_DESC·RATING_ASC)·`withPhotoOnly` 만 있고, 옵션 조건·추천 정렬·도움돼요가 없다.
- 앱 화면 초안: 사용자에게 보여 줌(2026-11-21). 계약이 생길 때까지 앱은 **목 모드로만** 만든다.

## 화면(초안)
- 상품리뷰 전체 보기: [사진리뷰만] … [추천순 ▾] / 둘째 줄 [옵션 전체 ▾](옵션이 2개 이상인 상품만).
- 정렬: 추천순 · 최근 등록순 · 별점 높은 순 · 별점 낮은 순.
- 리뷰 카드: 별점·날짜 아래 "옵션: 2개 묶음"(리뷰의 `sku` → 상품 옵션 라벨, 앱이 상품 상세 옵션으로 찾음), 맨 아래 [도움돼요 12].
  - 회원만 누른다(비회원이 누르면 로그인 안내). 누른 리뷰는 채운 모양·수 +1, 다시 누르면 취소.
  - 내가 쓴 리뷰는 버튼 없이 "N명에게 도움이 됐어요"만.

## 요청
- **R1. 추천순 정렬** — `sort` 에 `RECOMMENDED`(이름은 정해 주세요). 기준을 정해 알려 주세요.
  - 제안: 도움돼요 수 많은 순 → 같으면 최근 등록순. 사진 리뷰 가산 등 다른 기준이면 그대로 쓰겠다.
  - 기본 정렬을 추천순으로 바꿀지(지금 기본 NEWEST)도 알려 주세요. 앱은 정렬을 늘 명시해 보낸다.
- **R2. 옵션 필터** — 목록에 `sku` 조건(한 개, 없으면 전체). `withPhotoOnly`·`sort`·커서와 함께 쓸 수 있게.
  - 응답 `summary.reviewCount` 는 걸러진 수인지 상품 전체 수인지 정해 주세요(앱은 "리뷰 N개" 머리줄에 쓴다 — 걸러진 수면 좋다).
  - 앱이 받은 쪽만 걸러서는 수·다음 쪽이 맞지 않아 서버 조건이 필요하다.
- **R3. 도움돼요**
  - 누르기 `PUT /reviews/{reviewId}/helpful`·취소 `DELETE /reviews/{reviewId}/helpful`(모양은 정해 주세요) — 회원만(CUSTOMER), `Idempotency-Key`·`X-Source-System`. 이미 눌렀으면 그대로 성공(멱등).
  - 내 리뷰에는 못 누르게 422(예: `HELPFUL_OWN_REVIEW`), 게시되지 않은 리뷰(LOCKED·DELETED)는 409/422 — code 를 알려 주세요.
  - 응답에 바뀐 `helpfulCount`·`helpedByMe` 를 주면 앱이 그 값으로 바꾼다(앱이 +1 하지 않는다).
- **R4. 리뷰 응답 필드** — `Review` 에 `helpfulCount`(정수, 0 이상)·`helpedByMe`(불리언 — 회원 토큰이 있을 때만, 비회원·모름이면 null).
  - 목록 `GET /products/{productId}/reviews` 는 지금 `security: []` 라 회원 토큰이 와도 쓰지 않을 수 있다 — 토큰이 있으면 `helpedByMe` 를 채우도록(없으면 null) 부탁.
  - 내 리뷰 여부는 앱이 이미 `GET /me/reviews` 로 안다(별도 필드 필요 없음).
