# 추가 질문 — BR-103 네이버 프로필 사진이 배포 뒤에도 안 들어옴

- 보낸 앱: customer-app (PC 1)
- 받는 백엔드 영역: platform (auth-service · customer-service)
- 원 문서: `../pmart-backend/docs/handoff/clients/customer-app/2026-11-25-reply-br103-naver-profile.md`(사진 `?type=s256` 고침, customer-service 4dc42be7 배포)
- 계기: 사용자 2026-11-25 실기기 — 배포 뒤 네이버로 다시 로그인했는데 "네이버 프로필 사진 여전히 안 받아".

## 앱 쪽(확인함)
- 사진은 `GET /me` 의 `profileImageUrl` 이 있을 때만 보인다(사본은 `/me/profile-image` 인증 조회). 앱은 로그인 직후 2.5초·6초 뒤와 내 정보 열 때마다 `/me` 를 다시 읽는다(새 빌드, 실기기 설치 2026-11-25).
- 앱은 교환 응답 `profileImageUrl` 을 로그인·동의·휴대폰 확인 세 곳 모두에 넣는다.

## 확인 부탁(값은 빼고 있음/없음·결과만)
- Q1 이 사용자 계정의 **배포 뒤 마지막 네이버 로그인**: 교환 응답에 `profileImageUrl` 이 있었는지, auth `CustomerAuthenticated` 에 `pictureUrl` 이 있었는지.
- Q2 customer-service 사본 받기가 그 로그인에서 성공했는지(`?type=s256` 로 받았는지, 실패면 이유).
- Q3 이 계정 `photoSource` — 사용자가 앞서 앱에서 사진을 직접 바꾼 적이 있다. CUSTOM·NONE 이면 로그인 계정 사진으로 덮지 않는 규칙인지(그렇다면 앱에서 "로그인 계정 사진으로 되돌리기"를 눌러야 하는지).
- Q4 `GET /me` 가 지금 이 계정에 `profileImageUrl` 을 주는지.

## 추가(사용자 2026-11-25)
- 내 정보 → 사진 → **"로그인 계정 사진으로"(되돌리기)도 네이버 계정에서 안 된다.** 앱은 사진 바꾸기 계약대로 로그인 계정 사진 되돌리기를 보내고 서버 결과로만 바꾼다 — 서버가 이 계정의 네이버 사진 원본 주소를 아직 갖고 있지 않거나(사본 실패가 이어진 경우) 되돌리기가 거절되는지 확인 부탁.
- Q5 되돌리기 요청이 이 계정에서 어떤 결과였는지(성공·거절 코드·사본 실패), 네이버 사진 원본 주소가 저장돼 있는지(있음/없음).

## 추가 2(사용자 2026-11-25 오후 — 급함)
- 네이버로 가입(동의 화면에서 이름·이메일 필수·프로필 사진 허락)한 뒤 **앱을 다시 켜도, 다시 로그인해도** 마이페이지·내 정보의 이메일 등이 비어 있다. 앱은 `GET /me` 값만 보인다(앱 재시작 = `/me` 새로 읽기) — **서버 `/me` 에 이름·이메일·사진이 없다는 뜻**으로 보인다.
- Q6 이 사용자(오늘 탈퇴 뒤 네이버로 다시 가입한 계정)의 `GET /me` 에 지금 `name`·`email`·`profileImageUrl`·`socialProvider` 가 있는지(있음/없음), 마지막 `CustomerAuthenticated` 사건에 그 값이 실렸는지, customer 가 반영했는지. 탈퇴 뒤 재가입이라 계정이 바뀌면서 보관(sub 10분)이 앞 계정 쪽에 묶였거나 지워졌는지도.
