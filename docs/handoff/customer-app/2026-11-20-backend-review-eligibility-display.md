## 레퍼런스 화면(11-1 리뷰관리 — 리뷰 쓰기 탭)
- 맨 위 둘로 나눈 상자: **"리뷰 쓰기 5개 | 내가 쓴 리뷰 0개"** — 탭마다 전체 개수.
- 주문 묶음 머리: 가게(센터) 이름 + **주문 날짜**("2026.10.10 주문"), 그 아래 그 주문의 품목 카드들.
- 품목 카드: **상품 사진** + 상품명 + 옵션 + 남은 기한, 아래 별 5개.

## 지금 계약(review-service `Eligibility`)
`orderId · orderLineId · sku · productId · productName · deliveredAt · eligibleUntil · state · reviewId` — 개수·사진·주문 날짜·센터 이름이 없음.
`GET /me/reviews`(내가 쓴 리뷰)도 목록만 있고 전체 개수 없음.

## 요청
- R1. `GET /me/review-eligibilities` 와 `GET /me/reviews` 응답에 **전체 개수**(`total`) — 탭 머리 "N개". 첫 쪽만 받아도 정확한 수를 보이려면 서버 값이 필요(앱이 쪽을 다 읽어 세지 않는다).
- R2. `Eligibility` 에 **대표 사진**(`imageUrl`, 주문 당시 사본이든 지금 상품 사진이든 — 정해 주세요).
- R3. `Eligibility` 에 **주문 시각**(`orderedAt`)과 **센터 이름**(`mfcName`, 주문의 담당 센터 — order 0.15.0 `mfcName` 과 같은 값) — 주문 묶음 머리. 없으면 주문 ID 로만 묶는다.
- 품목 옵션 표시(`optionLabel`)도 있으면 함께(없어도 됨).

## 앱이 한 것(2026-11-20)
- 리뷰관리: 회색 둘로 나눈 상자(개수 없이 "리뷰 쓰기 | 내가 쓴 리뷰"), 테두리 카드(상품명·배송 완료·기한), 회색 별 5개(누르면 그 별점으로 쓰기), 오른쪽 "리뷰 쓰기" 글자 없앰.
