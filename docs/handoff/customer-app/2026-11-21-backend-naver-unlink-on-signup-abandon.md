# 요청 — BR-79 네이버 동의 뒤 가입을 그만두면 네이버 연결 끊기

- 보낸 앱: customer-app (PC 1)
- 받는 백엔드 영역: platform (auth-service)
- 이어지는 것: BR-74(auth 0.11.0 `purpose`·`naver.unlink-after-exchange`), ADR-0078(네이버 인가 코드 서버 교환), BR-72(동의 화면에서 나간 가입)
- 계기: 사용자 2026-11-21 "아직 동의만 하고 가입한 것도 아닌데 왜 (동의를 다시) 못 물어" → "카카오처럼 네이버도"

## 무엇이 문제인가
- 고객이 네이버 동의 화면에서 동의하면 네이버 쪽은 그 순간 "PMart 앱과 연결됨"이 된다. 그 뒤 우리 약관 동의·휴대폰 확인에서 나가 **가입을 끝내지 않아도**, 다음 네이버 로그인에서 네이버는 동의 화면(프로필 사진·이메일)을 다시 띄우지 않는다.
- 사용자는 가입을 끝내지 않은 사람에게는 다음에 동의를 다시 묻기를 원한다. 가입을 마친 회원에게 매번 묻는 것은 원하지 않는다.

## 앱이 한 것(카카오·구글)
- 카카오는 앱이 SDK `unlink()` 로 끊을 수 있어 앱에서 했다: 로그인 결과가 동의 대기(AUTH_CONSENT)·휴대폰 확인(AUTH_IDENTITY)인 채 로그인 화면을 떠나면 카카오 앱 연결을 끊는다. 구글도 같은 자리에서 `disconnect`(revokeAccess, 탈퇴 때 쓰는 것과 같은 호출)로 끊는다. 회원이 되면 끊지 않는다. 서버 변경 없음.
- 카카오 로그인은 카카오톡(없으면 카카오계정) 그대로 — 2026-11-21 의 "매번 로그인 화면(`prompt=login`)"은 사용자 결정으로 되돌렸다. 네이버 인가 요청의 `auth_type=reauthenticate` 도 되돌렸다(덧붙이는 값 없음). 회신 `2026-11-21-backend-social-login-chooser-and-revoke-reply.md` 의 2절 R2·R3 이 바뀐 것.

## 왜 서버가 해야 하나
- 네이버 연결 끊기(토큰 삭제 `grant_type=delete`)에는 client secret 과 네이버 access token 이 필요하다. 둘 다 서버만 갖는다(ADR-0078). 앱은 인가 코드만 받고 네이버 토큰을 갖지 않는다.

## 사용자 결정(2026-11-21)
- **(가)로 해 달라** — "네이버 1번 서버 변경으로 하자". 교환 때 그 `sub` 로 가입을 마친 계정이 없으면 교환 직후 끊는다. 앱 변경 없음.
- LAN `naver.unlink-after-exchange`(로그인마다 끊기)를 임시로 켜는 것은 고르지 않았다.

## 부탁
- **R1.** 네이버로 들어온 로그인이 **가입을 끝내지 않은 채 끝나면** 네이버 연결을 끊어 달라. 방법은 서버가 고른다. 이쪽에서 생각한 것:
  - (가) 교환(`POST /auth/naver-token-exchanges`) 때 그 `sub` 에 가입을 마친 계정이 없으면 교환 직후 끊는다. 가입을 마친 사람은 다음 로그인 때 한 번 더 동의를 보게 되지만, 그 뒤로는 끊지 않는다. 토큰을 들고 있을 필요가 없다.
  - (나) 동의 대기 동안 네이버 access token 을 서버가 들고 있다가(로그 금지, 동의 대기 만료와 같이 지움), 가입이 끝나지 않고 만료되거나 앱이 "가입 그만둠"을 알리면 끊는다. 앱이 알릴 경로가 필요하면 계약에 넣어 달라(예: `DELETE /auth/social-logins/{authRequestId}` — 같은 기기만, 멱등).
- **R2.** LAN 시험 설정 `naver.unlink-after-exchange`(로그인마다 끊기)가 지금 켜져 있는지 알려 달라. 켜져 있으면 R1 을 넣은 뒤 끄는 것이 사용자 뜻에 맞다(가입을 마친 회원은 매번 묻지 않음).
- **R3.** 끊기 실패는 로그인·가입을 막지 않는다(BR-74 와 같이). 토큰·`sub` 를 로그에 남기지 않는다.

## 앱이 할 일
- (가)면 앱은 바꿀 것 없다. (나)에서 앱이 알리는 경로가 생기면, 카카오와 같은 자리(가입 단계에서 로그인 화면을 떠날 때 — `LoginFlowController` 가 사라질 때)에서 부른다.
