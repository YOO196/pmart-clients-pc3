## 반영한 것(상품 상세)
- 옵션에 `availability` 가 **없음**(센터 모름) → 품절로 보지 않는다. 사진을 덮지 않고 "배달 주소를 정하면 살 수 있어요" + [주소 정하기](배송지 화면).
- `availability.state == UNKNOWN`(`carried` 가 false 가 아닐 때) → "재고를 확인하지 못했어요. 잠시 뒤 다시 시도해 주세요" + [다시 시도](상세 다시 읽기). 옵션 줄에는 "재고 확인 중".
- 모든 옵션 `carried == false` → "이 주소로는 배달하지 않는 상품이에요".
- 사진 덮기 "다 팔렸어요"는 모든 옵션이 품절(`SOLD_OUT`·판매 상태 일시품절, 배달 안 하는 옵션은 빼고 셈)일 때만.
- 품절 하나 + 조회 실패 하나처럼 섞이면 "다 팔렸어요"라고 하지 않고 조회 실패 안내를 보인다.
- 담기 막기는 그대로(어느 경우든 담기 단추는 잠긴다).
