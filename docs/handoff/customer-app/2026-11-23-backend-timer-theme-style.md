- 보낸 앱: customer-app (PC 1)
- 받는 백엔드 영역: platform (storefront-service) — 백오피스 편성 화면은 통합 백오피스(PC 2)에 넘겨 주세요
- 계기: 사용자 2026-11-23 "그 타이머 선택하는 걸 백오피스에 기능을 넣고 싶고". 초안 `../고객앱 ui/06_홈_타이머테마`(timer_section_drafts) 에서 사용자가 C·D 둘 다 쓰기로 함(11-21 "c랑 d 둘다 쓰고싶은데 둘다 킵해줘"). 어느 테마를 어떤 모양으로 보일지 운영자가 편성에서 고르게.

## 두 모양
| 값(제안) | 초안 | 앱에서 |
|---|---|---|
| `LABEL` | C | 제목 위 분홍 글자 "⏱ 05:12:30 남음"(알약 없음), 아래 제목 한 줄 + 부제, 전체보기는 오른쪽 |
| `BAND` | D | 머리를 연분홍 띠로 감쌈, 오른쪽에 시·분·초 칸 숫자 + "남은 시간", 전체보기는 상품 줄 아래 넓은 버튼 |

## R1. 편성 테마에 모양 값
- `LayoutTheme`(편성 초안·발행)에 `timerStyle: [LABEL, BAND]`(기본 LABEL). `showTimer=true` 일 때만 뜻이 있다(false 면 무시 또는 null).
- 홈 응답 `Section`(홈·MD 탭 내용 `GET /storefront/custom-tabs/{tabKey}` 의 영역도)에 같은 `timerStyle` 을 내려 주세요. 없으면 앱은 LABEL.
- 백오피스: 테마 편집에서 [남은 시간 표시] 를 켜면 모양(라벨형 / 띠형) 고르기. 미리보기가 있으면 두 모양을 그림으로.

## Q1. MD 탭 타이머는 이번 범위 밖으로 둬도 될까요?
- 탭 이름 위 남은 시간(`CustomTab.showTimer`)은 모양이 하나뿐이라 값이 필요 없다고 봄.

## 앱(받으면)
- `HomeSection.timerStyle` 로 C/D 머리를 고른다. 1초마다 갱신·끝나면 숨김(`SectionExpiry`)은 그대로.
