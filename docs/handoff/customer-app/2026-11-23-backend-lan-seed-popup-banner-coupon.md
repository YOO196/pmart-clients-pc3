# 요청 — LAN 시험 데이터: 홈 팝업·배너·쿠폰 몇 개

- 보낸 앱: customer-app (PC 1)
- 받는 백엔드 영역: platform (storefront·promotion)
- 계기: 사용자 2026-11-23 "프로모션 팝업 그냥 데이터가 없는거야? 안뜨길래" → LAN `GET /storefront/banners?placement=POPUP` 가 `items: []`(HOME_TOP·CATEGORY·SPLASH 는 있음). 사용자 "배너랑 쿠폰도 몇개 넣어달라고해줘". 계약 변경 아님 — 폰 확인용 시험 데이터.

## 요청
1. **POPUP 배너 2개**(서로 다른 이미지, 하나는 상품 연결·하나는 카테고리 연결, 기간은 넉넉히) — 홈 팝업 가운데 카드·넘김·"오늘 그만 보기" 확인용.
2. **배너 몇 개 더**: HOME_TOP 2~3개(넘김 확인), HOME_MIDDLE 1개, CATEGORY 1개 더(카테고리 화면 넘김 확인). 연결은 상품·카테고리·영역을 섞어서.
3. **쿠폰 몇 개**(promotion, 받을 수 있는 쿠폰함 "쿠폰 받기"):
   - 장바구니 쿠폰 정액 1개(예: 3,000원, 최소 주문 15,000원)
   - 정률 1개(예: 10%, 최대 할인 상한 있음)
   - 만료가 3일 안 남은 것 1개(쿠폰함 분홍 만료 칩 확인)
   - 받기 기간이 끝난 것 1개(받기 버튼 닫힘 확인), 가능하면
   - 모두 "모두 받기"로 받을 수 있게 회원 대상
4. 넣은 bannerId·쿠폰 이름을 회신에 적어 주세요(폰 확인 목록에 씀).

## 백엔드 회신(2026-11-23, PC1 백엔드 메시지)
- 넣은 배너: 팝업 B-POPUP-SOUP·B-POPUP-RAMEN, HOME_TOP B-TOP-DAIRY·B-TOP-MORNING·B-TOP-TOMATO, HOME_MIDDLE B-MIDDLE-RICE, CATEGORY B-CAT-ICE. 쿠폰 4개.
- 편성·진열·쿠폰 모두 **승인 대기**(승인 번호 LD-31bba49a·AP-7a5607cd) — 사용자가 백오피스에서 승인해야 앱에 보인다.
- 받기 기간이 끝난 쿠폰은 목록에 나오지 않아 만들지 않음.
