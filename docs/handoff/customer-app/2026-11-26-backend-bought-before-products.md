# 요청 BR-109 — "내가 1번 구매한 상품" 목록 API

- 보낸 앱: customer-app (PC 1)
- 받는 백엔드 영역: order (또는 storefront)
- 계기: 사용자 2026-11-26 홈 레퍼런스 — 카테고리 아래 "상품 고르는 시간도 아끼고 싶다면? / 내가 1번 구매한 상품 보기 ›" 카드, 누르면 한 번이라도 산 상품 모음.

## 지금
- 계약에 "본인이 산 상품(중복 없이)" 목록이 없다. `GET /orders` 는 주문 단위 + 줄 일부만이라 앱이 모으면 오래된 주문은 빠지고, 지금 살 수 있는지(판매 중·재고)도 모른다.

## 요청
- R1 `GET /me/purchased-products?cursor=&limit=` — 본인이 받은(배달 완료) 주문의 상품을 상품(또는 SKU) 단위로 중복 없이, 최근 산 순. 줄마다 `productId`, `sku`, `name`, `imageUrl`, `lastPurchasedAt`, `purchaseCount`, 지금 쇼핑 MFC 기준 `available`(판매 중·재고)·`price`.
- R2 홈 카드 사진용으로 첫 줄만 가볍게(`limit=1`) 받을 수 있게.

## 앱 처리(계약 전)
- 홈 카드는 주문이 있는 회원에게만 보이고(사진은 최근 주문 첫 상품, 서버 값), 누르면 주문내역으로 간다. 계약이 나오면 "구매한 상품" 화면으로 바꾼다.
