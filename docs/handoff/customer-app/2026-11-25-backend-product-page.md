# 요청 — BR-100 상품 상세 새 화면(사용자 레퍼런스 2026-11-25)에 필요한 값

- 보낸 앱: customer-app (PC 1)
- 받는 백엔드 영역: platform (product-content · product · review · customer · storefront · search), 백오피스(상품 편집·배너·기획전)
- 계기: 사용자 2026-11-25 상품페이지·리뷰 전체 보기 레퍼런스 제공 — "레퍼런스 그대로", 백엔드/백오피스 판단은 앱에 맡김.
- 레퍼런스: `docs/customer-app-design/4. 상품페이지, 상품 아이콘 분류/5. 상품페이지 전체 (2026-11-25 사용자 제공).jpg`, `6. 상품리뷰 전체 보기 (2026-11-25 사용자 제공).jpg` (이 PC 전용 폴더 — 필요하면 사용자에게 받기)

## 앱이 지금 계약으로 하는 것
사진·이름·평점 칸·할인가/정가/단위가격·배달팁 0원 줄(BR-96)·[상품설명|리뷰] 탭·구매 전 참고(보관방법 `storageGuide`)·상품설명(`description`·이미지)·반품·교환 안내(`returnGuide`)·같은 카테고리 인기상품(search `POPULAR`)·평점 좋은 상품(search `RATING`)·리뷰(평점·사진 모음·정렬·사진리뷰만·도움돼요·신고)·찜 하트.

## 요청 — 백엔드
- R1 상품 정보 칸(product-content): `origin`(원산지 문구), `expiryGuide`(소비기한/제조일 문구), `legalInfo[]`(상품정보제공고시 `{label, value}` 표). 지금은 `notices` 글줄에 섞여 있어 앱이 칸으로 나눌 수 없다(원산지만 "원산지:" 줄을 읽는다).
- R2 상세 설명 묶음: `descriptionBlocks[]` = `{type: TITLE|TEXT|IMAGE|OPTION_LABEL, text?, imageUrl?, sku?}` 순서대로(레퍼런스: 큰 제목 → 사진 → "옵션1 ○○" 꼬리표).
- R3 상품 찜 수 `wishCount`(상세 응답 또는 `GET /products/{id}/wish-count`) — 하단 하트 아래 숫자.
- R4 리뷰 작성자 프로필 사진 `authorImageUrl`(없으면 null)과 재구매 여부 `repurchased`(같은 상품을 전에도 산 회원).
- R5 추천: "다른 사람들이 함께 본 상품"(조회 기록)·"다른 사람들이 함께 구매한 상품"(주문 기록) — `GET /products/{id}/related?kind=VIEWED_TOGETHER|BOUGHT_TOGETHER&mfcId=` 같은 모양, 항목은 홈 진열 `ProductTile`. BR-98(장바구니 추천)과 같은 추천 담당으로 묶어도 된다.
- R6 상품 꼬리표 `badges[]`(최저가 도전·1+1·신선보장·증정품·사전예약 등 — 레퍼런스 `2. 뱃지 - *.jpg`) — 상세·카드(검색·진열) 모두.
- R7 카드 "N개 남음" — 검색·진열 카드의 재고 적음 수량(`lowStockQty`, 상세 `availableQty` 와 같은 기준, 적을 때만).
- R8 쇼핑 센터 고객용 이름(레퍼런스 "B마트 부산진구 ›") — 상세 응답 또는 주소 쇼핑 맥락.

## 요청 — 백엔드 + 백오피스
- R9 상품페이지 배너 자리 `PRODUCT_DETAIL`(storefront 배너 placement 추가 · 백오피스 배너 편성에서 고르기).
- R10 "함께 보면 좋은 기획전" — 이 상품이 들어간 진행 중 기획전(테마) 목록: 이름·끝나는 시각·대표 상품 사진 4장·전체 보기 연결. 백오피스 테마 편성에 고객 노출용 대표 이미지/기간이 없으면 함께.
- R11 R1·R2·R6 를 백오피스 상품 편집에서 입력.

## 백오피스
- 백오피스(PC 2) 화면 요청은 `docs/handoff/customer-app/2026-11-25-backoffice-customer-app-screens.md`(B-1 상품 편집 칸·B-2 배너 자리·B-3 기획전 — 이 문서 R9~R11). 계약을 정할 때 백오피스 입력 화면도 같이 봐 주세요.

## 질문
- Q1 리뷰는 사람이 검토한 뒤 공개되는가?(레퍼런스 말풍선 "모든 리뷰는 검토 후 보여드려요" — `SUBMIT_PENDING` 의 뜻). 아니면 앱은 이 문구를 넣지 않는다.
- Q2 공유 링크(상품 웹 주소·딥링크)를 둘 것인지 — 없으면 앱은 공유 버튼을 넣지 않는다.

## 앱 처리
- 계약이 생기기 전 R1~R10 칸은 목에서만 보이고 실서버에서는 그 칸을 빼고 그린다(지어내지 않는다).
- 넣지 않는 것: 배민클럽 특가 가격·배민페이머니 적립·"광고" 표시·리뷰의 "B마트" 꼬리표.
