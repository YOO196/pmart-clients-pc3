# 요청 — BR-104 비회원도 홈 쿠폰 행사 목록 읽기

- 보낸 앱: customer-app (PC 1)
- 받는 백엔드 영역: platform (promotion · api-gateway)
- 계기: 사용자 2026-11-25 "로그인 안 해도 첫 화면에 쿠폰 버튼 떠야지".

## 지금
- 홈 쿠폰 줄("첫주문 7,000원 할인쿠폰 외 3개")은 `GET /coupon-campaigns`(x-pmart-user-types CUSTOMER)로 그린다 — 비회원은 부를 수 없어 앱은 "로그인하고 할인 쿠폰 받기" 고정 안내 → 로그인으로 둔다.

## 요청
- R1 비회원(토큰 없이 또는 비회원 토큰)도 지금 진행 중인 쿠폰 행사 **목록만** 읽기(이름·할인·조건 — 회원별 값 `reachedLimit` 등은 빼거나 null). 받기(`POST`)는 지금처럼 회원만.
- R2 게이트웨이 공개 경로에 그 읽기를 더하기.

## 앱 처리
- 계약이 나오면 비회원도 서버 이름("첫주문 7,000원 할인쿠폰 외 N개")을 보이고, 누르면 쿠폰 시트 → [받기] 는 로그인 안내.
