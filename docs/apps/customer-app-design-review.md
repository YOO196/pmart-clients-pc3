## 2. 명세와 충돌하는 것 (결정 필요)
1. **1차 제외 범위** (`customer-app.md` :4: 쿠폰·프로모션·할인 배너·찜·재입고 알림·공유·AI 상담)
   - 레퍼런스에서는 이 기능들이 화면의 핵심 요소다: 쿠폰 영역, 1+1·증정·최저가 배지, 기획전과 광고, 찜 급상승, 재입고 알림(품절 상품의 주 버튼), 포인트 적립(리뷰 50/100원), AI 상담봇.
   - `[확정 2026-10-24]` 1차 제외를 유지한다. 이 영역은 그리지 않는다.
   - 할인율과 취소선 정가를 표시할지는 계약 `GET /prices` 에 정가와 할인가가 있는지 확인한 뒤 정한다.
2. **배달팁 무료 조건** (명세 :96, :98) — `[보류 2026-10-24]` 사용자가 나중에 정하기로 함
   - 명세: 상품액 30,000원 이상이거나 첫 구매면 0원이다.
   - 레퍼런스: 첫 주문일부터 30일·10회·1일 1회이고, 한집은 혜택을 받아도 1,000원이다. 30,000원 무료 기준은 보이지 않는다(3-1 홈의 띠 배너에만 있다).
   - 명세를 따른다. 레퍼런스 정책은 가져오지 않는다.
3. **최소주문 기준 금액**
   - 명세: 순수 상품액 기준이다.
   - 레퍼런스: 할인 후 금액 기준으로 보인다(5,990 + 9,010 = 15,000).
   - 서버 정의를 따르고, 화면에는 서버가 준 부족 금액만 표시한다.
4. **수령방법 선택 위치** — `[보류 2026-10-24]` 사용자가 나중에 정하기로 함
   - 명세: 별도 화면(SCR-DELIVERY-SELECT-001)에서 고른다.
   - 레퍼런스: 장바구니 안에서 고른다. 한집이 없으면 알뜰이 기본 선택되고, 한집이 있으면 기본 선택이 없다.
5. **주소 흐름**
   - 명세: 검색 → 지도 확인 → 상세.
   - 레퍼런스: 검색 → 상세(지도 미리보기) → 필요하면 지도 확인. 공동현관 비밀번호와 찾아오는 길이 별도 필드로 나뉜다.
6. **반품·교환 위치 차단**: 레퍼런스는 기기 위치가 주문 주소와 다르면 신청을 막는다. 업무 문서에 없는 규칙이므로 도입하지 않는다(필요하면 질문).
7. **주류 인증**
   - 명세 :118: "주류 판매(PG 인증)" `[결정 필요]`.
   - 레퍼런스: 휴대폰 본인확인(인증기관)으로 인증하고, 회원당 연 1회다. 인증 전에는 목록의 `+` 를 숨기고 상세 화면을 막는다.
8. **용어**: "한집배달·알뜰배달"은 배민 서비스명이다. 명세도 "한집/알뜰"이라는 말을 쓰고 있어 우리 명칭을 정해야 한다.

## 3. 명세에 없고 레퍼런스에 있는 것 (채택 후보)
- **온보딩**: 약관(위치기반 필수 / 마케팅 푸시 선택) → 로그인 또는 둘러보기(비회원) → 주소 등록. 마케팅 동의·거부 결과(일시, 처리결과)를 고지한다.
- **주소**: 상세주소 필수, 공동현관 비밀번호(라이더 전달 고지, 로그 금지 대상), 라이더 요청 프리셋 6종과 직접 입력. "우리집" 같은 이름 붙인 주소는 로그인이 필요하다.
- **홈**
  - 심야(00~08시) 안내 카드와 토스트
  - 배송방식 요약(예상시간 범위, 배달팁 범위)
  - 진행 중 주문 카드
  - 고정 탭과 동적 탭, 홈 아이콘을 다시 누르면 맨 위로 이동
  - 섹션 유형 A~H: 가로 카드, 칩과 2행 그리드, 순위 그리드, 카운트다운, 기획전, 배너, 무한 그리드
- **검색**: 오타 교정 안내, 결과 화면 안의 필터(중량·열량), 하단 장바구니 요약 바.
- **장바구니**
  - CTA 문구를 결제 조건 순서대로 바꾼다: 최소주문 → 수령방법 → (예약이면) 도착 시간 → "{방식} 주문하기 {금액}"
  - "N원 더 담으면" 문구와 진행 막대(서버 값)
  - 지점마다 다른 수령방법과 "지금은 준비 중" 표시
  - 수량이 1일 때 휴지통 아이콘, 재고 한도에서 `+` 비활성
  - 장바구니 보관 60일 안내
  - 네트워크 오류: 팝업 → 다시 조회 → 전체 화면 오류와 [다시 시도]
- **정책 모달**
  - 배달팁: "주문금액·거리·시간대·지역·할인에 따라 달라짐"
  - 봉투값: 일회용품 무상제공 금지 때문에 반드시 낸다
- **주문서**
  - 뒤로가기 시 "주문을 취소할까요?" 확인
  - 연락처 시트, 주문 안내 이메일
  - 품절 시 처리(부분/전체 취소 + 다음에도 적용)
  - 현금영수증(개인/사업자 10자리)
- **결제**: 토스 앱 미설치 안내, 가맹점 복귀 대기 화면("결제했다면 잠시만 기다려주세요" — 확정하지 않음. 우리 원칙과 맞는다).
- **배송현황**: 4단계 진행바(주문확인 → 상품준비중 → 배달중 → 배달완료), 남은 분과 도착 시각, 라이더 마커, 푸시 켜기 유도.
- **주문내역·상세**
  - 기간·가게·상태 필터
  - 같은 상품 담기(주문할 수 없는 품목은 빼고 담으며, 뺄 품목을 미리 확인시킨다. 품절 품목에는 대체 추천)
  - 취소 시 "장바구니에 다시 담기" 옵션
  - 환불 내역(환불 제외 금액, 복구 최대 7일)
  - 배송완료 뒤 버튼 전환(반품·교환 / 문의하기 / 현금영수증 / 리뷰)
- **예약시간 변경**: 상품준비 시작 전까지만 가능하다. 시간을 바꾸면 그 시간에 품절이 생겨 부분 취소될 수 있다. "주문일 기준 최대 N일" 상한이 있다(N 판독 불확실).
- **알림**
  - 종류와 누르면 가는 곳: 준비중·배달시작·배달중·곧 도착 → 배송현황, 배달완료 → 주문상세, 리뷰 유도(완료 10분 뒤)
  - **배송완료 뒤 옛 배송 알림을 누르면 배송현황 대신 주문내역 안내**
  - OS 권한 꺼짐 배너 → OS 설정으로 이동, 같은 종류 알림 묶음
- **리뷰**: 품목 단위, 별점 먼저, 텍스트 1,000자, 사진 10장, 정책 안내 팝업.
- **반품·교환**
  - 반품과 교환 진입을 분리하고, "앱에서 반품 불가" 주문 상태를 둔다
  - 사유 3그룹: 변심·실수 / 상품문제 / 배달문제. 문제 사유는 상세 이유(200자)와 사진(3장, 장당 20MB)이 필수다
  - 교환 불가 품목 목록과 사유
  - 같은 라이더가 회수와 재배달을 하고, 회수 요청과 재배달 요청을 따로 받는다
  - 변심 교환은 9,000원(명세와 일치), 문제 사유는 무료
  - 작성 중 이탈 확인
- **고객센터**: FAQ 검색과 칩, 채팅·전화 연결 상태, 주문 문의는 최근 2일 주문에서 고른다, 종료 확인, 만족도 5단계. 1차에서 AI 상담은 제외이므로 버튼형으로 정해진 흐름만 참고한다.
- **로딩**: 스플래시(기본/프로모션), 이미지 플레이스홀더, 무한 스크롤 하단 스피너. 홈 로딩은 레퍼런스처럼 빈 회색 화면이 아니라 스켈레톤으로 그리기를 권장한다.
