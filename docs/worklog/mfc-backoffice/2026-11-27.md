## DC 이관 입고 "전체"에서 끝난 TRF 가 빠지던 것 (사용자 2026-11-27 "T286575·W6307 mfc 에서 적치까지 완료했는데 백오피스에 안 떠")
- 원인: mfc-inbound `GET /inbound-promises` 는 state 를 비우면 끝나지 않은 것(EXPECTED·RECEIVING)만 준다. 탭 "전체"가 state 없이 불러 재고 반영(TIN_POSTED)된 TRF 가 빠졌다.
  목도 state 없으면 전부를 돌려줘 시험이 못 잡았다.
- 고침: "전체" = state 없이 + state=TIN_POSTED 를 함께 읽어 합침. 흐름 줄 "오늘 받음"은 date(예정 도착일) 대신 수령 postedAt 이 오늘(서울)인 것.
  목: state 없으면 EXPECTED·RECEIVING 만(서버처럼).
- 확인: typecheck·lint 통과, inbound 13 통과(전체에 재고 반영 TRF·TIN_POSTED 조회 확인 추가). 전체 327 중 324 — 실패 3은 app·me·ops 첫 화면 찾기 시간 초과(따로 45/45 통과).
