# 작업 일지 (worklog)

Claude Code가 이 저장소에서 수행한 작업의 "무엇을·왜·어떻게 검증했는지" 기록. 날짜별 1파일(`YYYY-MM-DD.md`), 항목은 시간순. 형식은 백엔드 `docs/worklog/README.md` 와 같다.

## 규칙
1. 커밋할 때 같은 커밋에 일지 항목을 포함한다(SHA는 다음 항목에 추기).
2. 실행한 검증만 적는다. 실행하지 않은 빌드·테스트는 "미실행"으로 미결에 둔다.
3. 구조 결정은 일지에 적은 뒤 `docs/adr/` 로 승격한다.
4. 비밀정보·개인정보·토큰은 적지 않는다.
5. 백엔드 계약 기준 커밋이 바뀌면 SHA와 영향 화면을 적는다.

## 항목 형식
```markdown
## HH:MM 제목
- 요청: 사용자의 말(요약 또는 인용)
- 한 일: 변경한 파일·범위
- 결정: 선택과 근거
- 검증: 실행한 명령과 결과
- 미결: 남은 것, 가정, 확인 필요
- 커밋: SHA
```
