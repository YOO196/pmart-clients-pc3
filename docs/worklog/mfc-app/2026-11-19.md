# 2026-11-19 mfc-app

## (PC 3) 패킹 끝 — PACK 실행 빼기, 서버 상태로 끝 판단
- 상황: 사용자 "기능 구현이 제대로 안 되어 있는데 정리하고 개선해". 백엔드 회신 감사 결과, "패킹 끝"이 아직 PACK 실행(`POST /tasks/{id}/executions` executionType PACK)을 큐에 넣어 보냄 — 계약은 "PACK 실적은 포장 밀봉으로, PACK 은 422". 실서버에서 끝 버튼이 422 로 거절됨.
- 고침: `PackingController.finish` 는 아무것도 보내지 않고 출고를 다시 읽어 READY·인계 중·인계됨이면 끝, 아니면 "아직 서버에서 패킹이 끝나지 않았어요", 조회 실패면 "확인하지 못했어요"(실패를 끝으로 바꾸지 않음). 끝 버튼은 확인 중 비활성. `packPayload` 삭제, 문구 `packingFinished`("실적을 보냈어요") 삭제.
- 목: PACK 실행은 422 `UNSUPPORTED_EXECUTION`, 다 밀봉되면 목 패킹 저장소가 목 작업 저장소에 알려 PACK 을 COMPLETED(서버와 같게).
- 낡은 주석 2곳(같은 주문 패킹 서버 보장 = BR-52 R20 → capacity 0.19.0).
- 확인: analyze 문제 없음, test 212개 통과(새 1개 — READY 아니면 끝 아님, 고친 1개 — 실행 안 보냄).
