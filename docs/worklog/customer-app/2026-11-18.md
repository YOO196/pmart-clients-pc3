- 리뷰 사진: 썸네일(`_ReviewPhotos`)을 누르면 `ReviewPhotoViewer`(전체 화면·옆으로 넘기기·두 손가락 확대·"n / N"·닫기). 못 그리는 사진은 "사진을 불러오지 못했어요". 새 라이브러리 없음.
- 품절 넘침: 칸 카드(가로 진열·격자)는 높이 고정(`heightFor`)인데 품절이면 상태 줄이 아래에 더해져 넘쳤다. 상태 문구를 사진 덮개 가운데로 옮기고(레퍼런스 "다 팔렸어요"와 같이) 칸 카드에서는 아래 줄을 뺐다. 세로 목록은 그대로. 넘침 시험에 실제 360dp 폭(98)을 더함 — 시험 글꼴이 실제 글꼴과 높이가 달라 148 폭 시험은 못 잡았다.
- + 버튼: 이미 담긴 상품은 "N개 있어요"만 알리고 보내지 않던 것을, 서버 담긴 수량 + 1 로 수량 변경(SetQuantity, 기대 버전)으로. 반영 뒤 "장바구니에 N개 있어요".
- 계정 줄 "계정 정보는 다시 로그인하면 보여요": 서버 프로필에 Google 이름·이메일이 없고, 로그인 때 SDK 이메일(메모리만)도 없을 때 — 앱을 다시 켜 세션을 되살리면 늘 비어 있다(카카오 로그인·프로필 미반영·조회 중/실패). 고치는 방법은 사용자 결정 대기.
- 검증: analyze 문제 없음, test 478 통과(새: 사진 보기 2·넘침 3·+ 버튼 1, 고침 1). 캡처 도구(실제 글꼴)에서도 넘침 오류 없음. 목 모드만.
